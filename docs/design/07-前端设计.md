# 07 前端设计（Vue3 · 蓝白水波纹）

## 1. 工程

| 项 | 选择 |
| --- | --- |
| 框架 | Vue 3.5（`<script setup lang="ts">`）+ Vite + TypeScript strict |
| 状态 | Pinia（`stores/auth.ts`、`stores/instance.ts`、`stores/site.ts`；管理端按页用组合式函数，不进全局 store） |
| 路由 | Vue Router 4，`createWebHistory()`；路由守卫处理登录、管理员、必须改密 |
| 组件库 | **Naive UI**（全局 `NConfigProvider` 注入主题覆盖，见 §2.4） |
| 原子类 | **UnoCSS**（`presetUno` + `presetIcons`（`@iconify-json/ph`）+ `presetAttributify` 关闭）；设计令牌同时以 CSS 变量与 Uno 主题提供 |
| 工具 | `@vueuse/core`（暗色偏好、窗口尺寸、`useIntervalFn`、`useEventSource`）、`dayjs`（相对时间，中文）|
| 请求 | 自写 `api/http.ts`：`fetch` 封装，统一错误（按 04 §0.2 错误码转中文提示）、401 跳登录、`MUST_CHANGE_PASSWORD` 跳改密 |
| 契约 | 从 `@dsh-hub/shared` 引类型与 zod schema；表单校验复用同一套 schema |
| 构建产物 | `apps/web/dist`，由 hub-api 托管；另有一个独立入口 `wake.html`（唤醒页，极小，无 Naive UI） |
| 不引入 | 大型图表库（概览页用 Naive 的进度条 + 自绘 SVG 迷你折线）、动画库（用 CSS + Vue `<Transition>`） |

## 2. 视觉规范（蓝白 · 水波纹）

关键词：**清透、留白、圆润、轻盈、水波**。参考 DeepSeek 官网的蓝白基调：白底 + 靛蓝主色（`#4D6BFE`），
点缀水青蓝、紫罗兰、琥珀、水绿；大面积浅蓝白背景 + 白色卡片；阴影带一点主色倾向；
水波纹是品牌动效（波浪、涟漪、状态点扩散），轻柔、缓慢、不抢内容的戏。

### 2.5 动效

| 场景 | 动效 | 参数 |
| --- | --- | --- |
| 路由切换 | 淡入 + 上移 8px | 220ms `cubic-bezier(.2,.8,.2,1)`，`<Transition mode="out-in">` |
| 卡片悬浮 | 上浮 2px + 阴影加深 | 180ms |
| 按钮按下 | `scale(.98)` | 120ms |
| 水波纹背景（登录/注册/唤醒页，`<WaterBackdrop>`） | 三层波浪横向平移（视差，后 34s / 中 28s 反向 / 前 22s）+ 上下轻晃；两处各三圈同心涟漪环向外扩散（7s 一轮，错开 1/3 周期）；两团柔光漂移 26s | 纯 CSS 无限循环；波浪 svg 宽 200%、含两个周期，平移 -50% 无缝循环 |
| 指针涟漪（登录/注册页，`useWaterRipples`） | 鼠标划过落小水纹（≥ 30px 且 ≥ 110ms 一个）、点击落大水纹（3 圈）、每 2.2–4.4s 随机落一滴「雨」 | 画布 + rAF，只在有涟漪时才跑帧；同时最多 18 个；颜色取 `--c-primary` |
| 工作台 / 管理端背景（`<WaterBackdrop variant="calm">`） | 视口底部固定的两层淡波浪（前 + 后），无涟漪环与指针交互 | 同上 CSS 波浪，整体 `opacity .85` |
| 按钮点击 | Naive UI 自带的按钮水波扩散（颜色随主色） | 不另写 |
| 列表进入 | 逐项淡入，间隔 30ms（最多前 10 项） | `<TransitionGroup>` |
| 实例运行中 | 状态点向外扩散涟漪（颜色随状态色，`--breathe-color`） | 2.4s `box-shadow` 扩散 7px 并淡出 |
| 启动中 | 「正在唤醒」：品牌水滴 + 三圈涟漪向外扩散，进度阶段文字切换 | 见唤醒页 |
| 数字 | 概览数字从 0 计数到目标 | 600ms，`requestAnimationFrame` |
| 成功反馈 | 勾号描边动画（SVG `stroke-dashoffset`） | 400ms |
| 骨架屏 | 浅蓝色流光 | 1.4s |

### 2.7 界面文案：不放常驻说明小字（2026-10-16 起，WP14）

DSH Hub 是要交付给最终用户的产品，**页面上不常驻解释性小字**（页面副标题、卡片描述、表单项下面的灰字、表格上方的说明行、
「点 … 可以 …」「失焦后 …」这类教用户怎么操作的句子）。界面要靠控件、名称和状态把意思说清。处理一条小字时按顺序判断：

1. **删**：标签、按钮文字、占位符、列标题、空状态已经说清的，解释删掉。教操作方法的句子一律删，交互本身做到不用教（做不到就改交互）。
2. **挪到它该在的位置**：单位进输入框后缀或列标题（「输入 · 积分/百万 token」）；格式、范围、示例进占位符（短）；
   名字本身写清楚（比如按钮写「保存并下发」，不要「保存」加一行「记得下发」）。
3. **按状态出现**：只在相关时才出现的提醒，用正式组件（`NAlert`、状态胶囊、行内标记），比如「配置有改动，还没下发」只在待下发时出现。不能常驻。
4. **放进确认框**：操作的后果（删除、重建容器、影响 N 个用户、扣积分）写在确认框正文里，不在页面上预先提醒。
5. **少数人才关心、但确实需要的说明**：在标签或列标题后放 `InfoTip`（`components/base/InfoTip.vue`，「ⓘ」悬停 / 聚焦 / 触屏点开）。
   **每个页面（含弹窗）最多 3 个**；不要把删掉的小字原样搬进去，写成一两句。
6. **保留**：表单校验错误（红字，字段下方，读屏可读）、空状态的一句引导、数据本身（时间、副名称、峰值等）。

另外：`hub-muted` 只给次要**数据**用（时间、副名称），不给解释句用；不把必须知道的操作信息只放在 InfoTip 里；
不为了删小字删掉错误、危险提示。检查工具：`apps/web/scripts/audit-ui.mjs`（列出每页的小字与断行）。

### 2.8 不该断的行

- **以下内容不能从中间断开**：标识符（模型名、用户名、slug、密钥前缀、任务号、版本号、URL、包名、文件名）、
  数字、数字 + 单位（「24.2万 token」「0.2886 积分」「1,000,000」）、日期时间、状态胶囊 / 标签 / 按钮文字、列标题、
  成对的「标签 + 值」（「token 24.2万」）。
- **做法**：`white-space: nowrap`；地方不够就**单行省略**（`text-overflow: ellipsis`，完整内容放 `title` 或悬停提示，表格列用
  `ellipsis: { tooltip: true }`），或者给列足够的 `min-width`、表格加 `scroll-x`。**不准**用 `word-break: break-all` / `overflow-wrap: anywhere` 拆标识符。
  一行里有几组「数字 + 单位」时，换行只能发生在组与组之间。
- **可以换行**：段落正文、长描述、备注、错误信息。
- **表格**：标识符列要么够宽，要么省略 + 悬停看全；手机 390 时表格在卡片里横向滚动，不要把列挤成每格两三行。
- **浮层**：图表悬浮提示、统计卡片里的数值永远单行；浮层宽度按内容（`width: max-content`），不受触发元素宽度限制。
- 检查宽度 **1440 / 1280 / 1024 / 390**。

### 10.2.1 图表与指标（WP56h「能用图的不要用表」）

渲染器全部 SVG 自绘（沿用 `niceTicks` / 新增的 `monotoneCubicPath`、`formatCompactNumber`），不引图表库。
颜色只从 `--c-series-1..6` / `--c-series-other` 与语义色取，**渐变 = 系列色 + 透明度**，不新增色值；
不属于任何系列的那几层走 2026-10-30 追加的令牌：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--b-glass` / `--b-glass-shadow` / `--b-glass-blur` | `rgb(14 23 44 / 88%)` 等 | 悬停浮层（玻璃质感：半透明底 + 模糊 + 外阴影） |
| `--b-gauge-track` | `rgb(120 160 240 / 16%)` | 环形仪表 / donut 的细轨道 |
| `--b-bar-fill` | `rgb(70 200 255 / 12%)` | 表格数值列背后的数据条（天空色低透明度） |
| `--b-stat-glow-neutral/-good/-warn/-bad` | 对应语义色的 0 0 18px 辉光 | 指标大数字的微辉光（按 tone） |

视觉规则：
- 折线/面积：单调三次曲线（不过冲）、面积纵向渐变（系列色 35% → 0%）、2px 描边 + 轻辉光、描线入场 600ms、
  刷新时数值 260ms 插值、最后一点呼吸光点；悬停竖向十字准线 + 玻璃浮层（等宽数字）。
- 柱/堆叠柱：顶部 3px 圆角（基线以下裁剪成方边）、纵向渐变、柱 ≤12 根时柱顶标数值（紧凑写法）、
  入场从底部长出 500ms / 错峰 30ms。
- donut：14px 粗环、段间 2px 缝、中心总数 + 单位、图例带百分比，入场逐段扫出。
- stats：28px 等宽半粗数字 + 小标签；`delta` 用 ▲▼ 带色；`max` → 44px 环形仪表；`spark` → 64×20 迷你面积线；
  数值变化时 400ms 滚动计数（首帧直接落值）。
- 坐标轴：发丝虚线网格、等宽小号刻度、左上角单位标注、大数字紧凑（`1.2M` / `45.3K`）。
- 表格：行数 ≤20 时数值列画数据条（按列最大值归一）；空表不留空表头，说一句人话
  （「一切正常」「没有待确认的操作」）。
- `prefers-reduced-motion: reduce`：全部入场/计数/呼吸动画关闭（组件里连动画类都不加），直接显示终态。

### 10.3 iframe 嵌入（App 网页版）
`/m/?embed=cockpit&theme=bridge#code=<交接码>`：同源 iframe、背景透明、强制深色；
**父页面的 `<iframe>` 元素必须写 `color-scheme: dark`**：否则 Chrome 判定嵌入方与文档的 color-scheme 不一致，
给 iframe 垫一层不透明的 `#121212`，中控台会变成一块中性灰（只看 `getComputedStyle` 查不出来，要截图取像素）；
子→父 `cockpit.ready/session/auth-expired/focus-canvas/focus-proposal/turn`；
父→子 `cockpit.focus-session/prefill/handoff`；双方校验 `event.origin === location.origin`。

  `running` 之后只靠 SSE（Hub 不会为「自动拉起」推 `ops.status`）。
- I6：座舱停止/模型不可用时，两舷态势板与已创建的方案照常可用，胶囊显示原因。

### 10.5 画布与方案卡
- 投放：数据类投左舷、行动类（proposal/secret/job）投右舷；`placement:'auto'` 由 Hub 解析后写回卡片；
- 方案卡：风险徽章、影响面（Hub 计算）、「DSH 的说明」、执行/拒绝、R3 要密码；
- 密钥卡：密码框 + 用途 + 来源会话，值只发 Hub，DSH 只拿引用号；
- 角标：`Hub 数据`（source 卡）/ `DSH 计算`（内联数据）。

# 21 统一下发：实例与桌面端同一入口 · 已安装用户 · 一次多个插件

> 2026-10-22 用户需求（原话要点）：①桌面端的下发管理和之前的合并，下发时选「实例」或「桌面端」；②下发插件或 API 时，「下发给谁」增加「已安装用户」，方便批量升级；③插件页支持一次选多个插件再执行下发或安装，不用一个一个点。
> 契约已写好并合入：`packages/shared/src/api/delivery.ts`（唯一真相；本文档是它的设计说明）。任务包：任务书（未随开源版发布）。

## 0. 现状与要解决的问题

| | 实例（Docker 容器里的 DSH） | 桌面端（用户电脑上的 DSH Hub 桌面端） |
|---|---|---|
| 下发入口 | 管理台「下发向导」`/admin/rollouts`（动作 → 目标 → 策略 → 预览+二次密码），任务引擎 `rollouts` + `jobs` | 管理台「桌面端」页（总览 / 插件 / 配置片段 / 版本与升级），清单服务 `desktop-delivery` |
| 目标 | 全部 / 指定用户 / 按条件（含「装了某插件」） | 全部 / 角色 / 指定用户 |
| 一次下发几个插件 | 一个 | 一个 |
| 已安装用户 | 有（`filter.pluginId`），但向导里没有一等入口 | 没有；设备上报了插件清单（`desktop_device_plugins`）但没人用它选目标 |

两套入口、两套目标语义，管理员要来回切，升级一个插件要在两边各点一遍、每个插件各点一遍。

## 1. 目标形态

1. **一个下发向导**（沿用 `/admin/rollouts`）：第 1 步选**平台**（实例 / 桌面端，可同时选）和**内容**（插件，可多选；模型与 API 配置；DSH 版本，仅实例）；第 2 步选**动作**和**目标**（全部 / 指定用户 / 角色 / **已安装用户**，可勾「只选版本较旧的」）；第 3 步策略（仅实例侧有）；第 4 步预览（按平台分组、桌面侧一台设备一行）+ 二次密码确认。
2. **插件库页多选**：列表加勾选列和批量操作条（下发 / 安装、升级已安装用户、卸载），点了跳向导并预填；列表新增「已安装」列（实例 N 人、桌面 M 台、其中 X 个版本较旧）。
3. **桌面端页收窄**：不再放「新增下发」的表单，只保留桌面端特有的东西——总览与设备状态、已下发清单（查看 / 撤回）、配置片段中非模型的条目（代理 / pip 镜像 / pilot 的 hubMode）、版本与升级（安装包、渠道目标版本、灰度、强更地板）。桌面端的「新增插件下发」「模型预设下发」改走统一向导。
4. 旧接口全部**保持可用**（`POST /api/admin/rollouts`、`/api/admin/desktop/*`），统一下发是在它们之上的编排层，不改旧行为。

## 2. 关键语义（已定，任务包照此执行）

- **内容项**：`plugin`（`versionId` 省略 = 最新）、`models`（模型与 API/渠道配置：实例 = 既有「模型配置」下发；桌面 = 更新 `llm-pi-ai` 与 `agent-default-model` 两个配置片段，按系统预设或 `presetId`）、`runtime`（仅实例）。一次最多 20 项。
- **已安装用户**（`targets.mode='installed'`）：每个内容项各自解析，**在提交那一刻落成明确的用户清单**写进任务与审计（之后新装的人不会被追加）。
  - `plugin`：实例 = `user_plugins` 期望状态为已安装；桌面 = 设备上报的插件清单里有该包。`outdatedOnly=true` 只取版本低于本次要下发版本的。
  - `models`：实例 = 容器已渲染过 Hub 路由的用户；桌面 = 已登录的有效设备。
  - `runtime`：不支持。
- **桌面侧的执行**：只写「期望状态」——一次提交只生成**一个**新的清单版本（`revision`），设备按心跳拉取；没有桌面整包的插件版本整项跳过并在结果里说明；已吊销设备不进目标。桌面侧「配置片段」是**按目标整体替换**的，写 `models` 时必须读出该目标现有片段、只替换这两个条目，不能冲掉别的片段。
- **实例侧的执行**：每个内容项一个 job，复用现有 rollout 服务（金丝雀、并发、失败比例、重启策略不变）。
- **二次密码、审计**：提交需要 `requireReauth`，审计 `delivery.create`（detail 里写平台、内容项、动作、目标模式与解析出的人数，不写用户清单全文超过 50 人时只写前 50 个 + 总数）。
- **预览**不改任何状态；行数上限 2000，超出 `truncated=true`（执行仍按完整清单）。

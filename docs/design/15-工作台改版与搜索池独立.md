## 1. 管理端：搜索池独立成页（R1）

- 新路由 `/admin/search`，名字是 `AdminSearch`，标题是「搜索池」。左侧导航放在「模型」的正下方，图标用 `i-ph-magnifying-glass`。
- 页面就是原来「模型 → 搜索池」标签的内容（`components/admin/relay/tools/RelayToolsTab.vue` 里的设置 / 概览 / 渠道 / 用量）。原来是嵌在标签里的子标签，现在提升为本页的一级标签，`?tab=settings|overview|channels|usage` 与地址栏同步；没带 tab 时默认打开「概览」。
- 「模型」页去掉「搜索池」标签。旧地址 `/admin/models?tab=tools` 要直接跳到 `/admin/search`，不能落到「概览」。
- 设置页里「需要下发并重启用户实例后生效」的提示和下发向导链接保持不变。原因是工具配置不进 config_hash，要跑一次模型下发才会生效（见 14）。
- 组件目录可以顺手从 `components/admin/relay/tools/` 移到 `components/admin/search/`，也可以不动。挪了的话，import 和测试要一起改干净。

## 2. 用户端

### 2.1 工作台 `/home` 新顺序

从上到下：

1. 公告条 + 问候语（不变）。
2. **我的 DSH**（`#dsh`）：主卡片（状态、打开 / 停止 / 重启、CPU 和内存用量），卡片里新增一条「当前配置」：
   - **计费开启**（`MyComputeResponse.billingEnabled`）：显示当前规格的 `planSpecText` 和价格，形如「2 核 · 4 GB　0.3 积分/小时（每 10 分钟 0.05）」。实例在跑且有租约时，用租约里的规格快照（`lease.planName / cpus / memoryMb / pricePerHourMicro`）；没在跑时用 `selectedPlanId` 对应的规格。旁边放「切换配置」按钮，点开弹窗，里面是现有的规格卡片（`ComputePlans`）和联系文案。选中规格后的行为和现在一样：停止中只记住；运行中先弹现有的确认框，确认后按新规格重启。管理员本人免计费（`exempt`）时，价格后面加「（管理员免计费）」。
   - 余额条（`ComputeBalanceBar`）和当前租约信息（`ComputeLeasePanel`）放在主卡片下方紧挨着，或者收进主卡片底部，选更紧凑的一种。原来独立的「算力租赁」大卡片（`HomeCompute`）不再单独占一块。
   - **计费关闭**：显示「当前配置 2 核 · 4 GB · 暂不计费」，规格取 `quota.cpus / quota.memoryMb`，不显示「切换配置」。原因是计费关闭时实例按 Quota 运行，规格不起作用（13 §4）。
   - 余额不足、没有可选规格时，启动按钮的禁用逻辑保持不变。
3. **我的模型**（`#models`）：见 §2.2。
4. **我的插件**（`#plugins`）：把现有 `components/user/me/MyPluginsTab.vue` 的完整功能（卡片网格、必装带锁、可选开关、每 3 秒轮询）整体搬过来，作为一个区块直接显示。原来只显示数量和前 5 个图标的 `MyPluginsCard` 删掉。
5. **我的数据**（`#data`）：把 `ExportsTab.vue`（勾选、导出进度、历史）整体搬过来。`ExportCard` 删掉。
6. 工作台的最后一块是插件/数据区，没有「DeepSeek 账号」卡片。

每个区块用统一的区块标题（`SectionTitle` 或 `SoftCard` 的 title）。手机宽度下各区块单列，不能出现横向滚动。区块的锚点 id 就是上面括号里的值，旧链接会跳到这些锚点（§2.4）。

### 2.2 我的模型（R5 的「补上计费信息」）

- **中转站已开通**（`/api/me/relay` 的 `enabled=true`）：
  - 顶部一行显示默认模型（`modelSummary.defaultModel`），保留「由管理员统一配置」的锁和说明。还要保留积分余额和本月已用这一行，链接到 `/usage`。
  - 下面是模型列表，每行显示：模型名（可复制）、显示名、**输入 / 输出 / 缓存读价格（积分 / 百万 token，已经乘上渠道倍率；倍率不同时显示区间，规则和 `RelayModelsTable` 一样）**、上下文长度；默认模型的那一行带「默认」标签。
  - 过滤规则：用户是统一管理（`policy === 'managed'`），并且返回的模型里至少有一个带 `inDsh` 字段时，只列 `inDsh === true` 的模型，也就是用户 DSH 里真能看到的。其他情况列出全部 `models`。默认标签优先看 `dshDefault === true`，没有这个字段时用名字和 `defaultModel` 相等来判断。
  - 钱包倍率不是 100% 时，在列表上方加一句小字：「你的价格为标价的 N%」。实际扣费 = 价格 × 渠道倍率 × 钱包倍率。
  - 手机宽度下改成卡片列表（模型名在上，价格成对排在下面），不要做成横向滚动的宽表。
- **中转站未开通**：和现在的 `ModelCard` 一样，只显示默认模型和提供方。

### 2.5 去掉「小草」（R7）

- 工作台主卡片左边的状态插画（`InstanceArt`：运行中 / 启动中是发芽的叶子，停止是睡觉的云，异常是小猫）换成**用户头像**（`AvatarImg`，桌面 96–120px，手机适当缩小），实例状态用头像外的一圈状态色环，或者右下角的状态点来表示（运行中用成功色，启动 / 停止中用主色并带呼吸动效，停止用灰色，异常用危险色；`prefers-reduced-motion` 时不播动效）。状态文字仍由卡片里原有的 `StatusPill` 显示。`InstanceArt.vue` 不再被引用时就删掉。
- 登录页去掉 `KeyLeaf` 插画，只留标题和副标题，间距重新调好。注册页「当前没有开放注册」那里的 `LeafSprout` 也一起去掉，保证认证页统一。
- 顶栏右上角本来就显示头像，不用改。左上角的鲸鱼品牌标识不属于「小草」，**保留**。
- `EmptyState` 默认的叶子插画、样式自查页里的插画这次都不动。用户说「回头需要什么我再想想」，暂不扩大范围。

## 3. 后端（小改）

### 3.1 默认规格（R2）

- 契约：`ComputeSettings.defaultPlanId: string | null`，默认值 `'c2m4'`；`PATCH /api/admin/compute/settings` 接受这个字段（可选，可以传 null）。已经存进库的设置里没有这个字段时，按默认值合并（settings-store 现在就是这样合并的）。
- `preferredPlanId` 的取值顺序：用户自己选过、而且这个规格现在仍然可选 → 用它；否则看 `defaultPlanId`，它对这个用户可选 → 用它；再不行就用第一个可选规格；一个可选规格都没有 → null。
- 注册时**不写** `compute_prefs`。这样管理员以后改默认规格，所有还没自己选过规格的用户都会跟着变。
- 修改 `defaultPlanId` 要记审计（并进 `compute.settings.update` 的 detail）。
- 管理端「系统设置 → 算力租赁」加一个「新用户默认规格」下拉框：选项是启用中、对所有人可见的规格，外加一项「第一个可选规格」（对应 null）。当前选的规格被停用或删除时，下拉框旁边显示警告「该规格已不可用，将退回第一个可选规格」。
- 计费关闭时，实例照旧按 Quota（默认就是 2 核 4096 MB）运行，不受这个字段影响。

### 3.2 我的模型里的「在 DSH 中」标记

- 契约：`MyRelayModel.inDsh?: boolean`、`MyRelayModel.dshDefault?: boolean`（在 `/api/me/relay` 的 `models[]` 里）。
- `inDsh`：这个模型在「下发到 DSH」的选中集合里，并且现在能下发（启用，有可用路由，`blockedReason === null`）。`dshDefault`：这个模型是下发配置里的默认模型。两个字段都和用户自己的 `modelPolicy` 无关（前端自己看 policy 决定怎么用）。
- 不要把这些计算放进 `myModels(role)` 的热路径做 N 次查询：一次读出选中集合和默认模型，再一起标记。

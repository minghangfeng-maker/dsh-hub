## 与实现的关系

- **契约**：`packages/shared/src/api/*.ts` 是唯一真相；`contract-map.ts` 登记「接口 → schema」，
  `packages/shared/test/contract.test.ts` 会核对覆盖率。文档与代码冲突时以代码为准。
- **数据库迁移**：`apps/api/src/db/migrations/*.sql` 编号连续、只增不改。开源版删掉了三个功能
  （网络代理、非官方模型池接入、DeepSeek 账号登录）的代码与界面，但**迁移文件保留不动**——
  编号要连续，已有部署的库也不用回滚。所以：**部分迁移建的表在开源版里没有任何代码读写**，
  留着当历史痕迹（不要照着表名去找功能）。
- **历史记录**：进度报告、任务书、技术验证记录不随开源版发布，文档里不再引用它们。
- **示例值**：文档里的域名一律是 `hub.example.com` / `edge.example.com`，IP 用 TEST-NET
  （`192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`），路径用 `~/dsh-hub-prod` 这类通用写法。

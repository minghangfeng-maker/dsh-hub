# 03 数据模型

## 1. SQLite（`HUB_DATA_DIR/hub.db`）

约定：
- `node:sqlite` 的 `DatabaseSync`；启动时 `PRAGMA journal_mode=WAL; foreign_keys=ON; busy_timeout=5000`。
- 时间一律存 **ISO-8601 UTC 字符串**（`2026-10-12T13:00:00.000Z`）。
- JSON 字段以 `_json` 结尾，存 TEXT，读写经 zod 校验。
- 加密字段以 `_enc` 结尾：`v1:<ivB64>:<tagB64>:<cipherB64>`（AES-256-GCM）。
- 跨任务包的引用（如 `users.runtime_id → runtimes`）只做**逻辑外键**，不写 `REFERENCES`，避免迁移顺序耦合。
- 迁移文件 `apps/api/src/db/migrations/NNN_<name>.sql`，按编号顺序执行，记录在 `schema_migrations`。
  **编号段按任务包分配，避免并行开发撞号**：WP0a `000–001`（基础设施表 `settings`、`audit_logs` 与所有模块都依赖的 `users`、`sessions`），WP1 `002–019`，WP2 `020–039`，WP3 `040–059`，WP4 `060–079`，relay `080–099`，compute `100–119`（13 §5），**桌面端 `120–139`（20 §5：120 设备台账、121 设备令牌、122 下发与升级；WP25e 没有新迁移）**。

### 1.1 账号域（`users`/`sessions`/`settings`/`audit_logs` 由 WP0a 建表；其余 WP1）

```sql
CREATE TABLE users (
  id                   INTEGER PRIMARY KEY,
  slug                 TEXT NOT NULL UNIQUE,            -- 不可变，'u' + 7 位 [a-z0-9]
  username             TEXT NOT NULL UNIQUE,            -- 可修改，小写
  display_name         TEXT NOT NULL DEFAULT '',
  bio                  TEXT NOT NULL DEFAULT '',
  avatar_file          TEXT,                            -- avatars/ 下的文件名
  password_hash        TEXT NOT NULL,
  role                 TEXT NOT NULL DEFAULT 'user' CHECK (role IN ('user','admin')),
  role_label           TEXT NOT NULL DEFAULT '',        -- 普通用户的自定义角色名（如「家人」）；只是显示名，权限只看 role；空串 = 「普通用户」，管理员恒为空串（迁移 004）
  status               TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('pending','active','disabled')),
  must_change_password INTEGER NOT NULL DEFAULT 0,
  quota_json           TEXT,                            -- 为空则用全局默认，见 §1.5 Quota
  runtime_id           INTEGER,                         -- 钉住的 DSH 版本（逻辑外键 → runtimes）；为空则用默认版本
  model_preset_id      INTEGER,                         -- 逻辑外键 → model_presets；为空则用默认预设
  model_policy         TEXT NOT NULL DEFAULT 'managed' CHECK (model_policy IN ('managed','free')),
  username_changed_at  TEXT,
  last_login_at        TEXT,
  last_login_ip        TEXT,
  created_at           TEXT NOT NULL,
  updated_at           TEXT NOT NULL,
  deleted_at           TEXT,                            -- 软删除（进回收站）
  deleted_username     TEXT,                            -- 删除时的用户名；删除即释放 username（改成 `<原名>#del<id>`），恢复与展示都用这一列（迁移 006）
  deleted_from_status  TEXT,                            -- 删除前的 status，恢复后回到它（迁移 006；存量为空按 active 处理）
  purged_at            TEXT,                            -- 彻底删除时间；为空 = 还在回收站（迁移 006）
  trash_dir            TEXT                             -- 数据目录在 trash/ 下的相对路径；没有数据目录时为空（迁移 006）
);

CREATE TABLE sessions (
  id           TEXT PRIMARY KEY,                        -- sha256(token) hex
  user_id      INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at   TEXT NOT NULL,
  last_seen_at TEXT NOT NULL,
  expires_at   TEXT NOT NULL,
  reauth_at    TEXT,                                    -- 最近一次二次验证密码
  ip           TEXT,
  user_agent   TEXT,
  revoked_at   TEXT
);
CREATE INDEX sessions_user ON sessions(user_id);

CREATE TABLE invites (
  id          INTEGER PRIMARY KEY,
  code        TEXT NOT NULL UNIQUE,                     -- 12 位，大写字母数字，去掉易混字符
  note        TEXT NOT NULL DEFAULT '',
  max_uses    INTEGER NOT NULL DEFAULT 1,
  used_count  INTEGER NOT NULL DEFAULT 0,
  expires_at  TEXT,
  disabled    INTEGER NOT NULL DEFAULT 0,
  created_by  INTEGER REFERENCES users(id),
  created_at  TEXT NOT NULL,
  role_label  TEXT NOT NULL DEFAULT ''                  -- 用此码注册的人得到的角色名（迁移 005，WP9）；只能是普通用户标签，邀请码永远给不了管理员
);
CREATE TABLE invite_uses (
  invite_id INTEGER NOT NULL REFERENCES invites(id),
  user_id   INTEGER NOT NULL REFERENCES users(id),
  used_at   TEXT NOT NULL,
  PRIMARY KEY (invite_id, user_id)
);

CREATE TABLE settings (                                 -- 键值，见 §1.6
  key        TEXT PRIMARY KEY,
  value_json TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE TABLE audit_logs (
  id          INTEGER PRIMARY KEY,
  at          TEXT NOT NULL,
  actor_id    INTEGER,                                  -- 可为空（匿名，如登录失败）
  actor_ip    TEXT,
  action      TEXT NOT NULL,                            -- 'auth.login.success' 等，见 04 §9
  target_type TEXT,                                     -- 'user' | 'instance' | 'plugin' | ...
  target_id   TEXT,
  detail_json TEXT
);
CREATE INDEX audit_at ON audit_logs(at);
CREATE INDEX audit_actor ON audit_logs(actor_id);
```

### 1.2 实例域（WP2）

```sql
CREATE TABLE instances (
  user_id         INTEGER PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  container_id    TEXT,
  container_name  TEXT NOT NULL,                        -- 'dshhub-' || slug
  runtime_id      INTEGER,                              -- 当前容器实际使用的版本（逻辑外键 → runtimes）
  image           TEXT,
  status          TEXT NOT NULL DEFAULT 'absent'
                  CHECK (status IN ('absent','stopped','starting','running','stopping','error')),
  ip              TEXT,
  authority       TEXT,                                 -- Hub 发给 DSH 的 Host，统一 '127.0.0.1:3000'（05 F4/F14）
  config_hash     TEXT,                                 -- 创建容器时的规格哈希（镜像+配额+env 键+managed 版本）
  started_at      TEXT,
  last_active_at  TEXT,
  start_reason    TEXT,                                 -- 'user' | 'admin' | 'rollout' | 'login'
  bootstrapped_at TEXT,                                 -- 首次插件安装完成时间
  error           TEXT,
  updated_at      TEXT NOT NULL
);
```

`config_hash` 用来判断「规格已变化，需要重建容器」：配额、镜像、模型密钥 env 变化都会改变它；
状态页显示「配置已更新，重启后生效」。

### 1.3 任务域（WP4）

```sql
CREATE TABLE jobs (
  id           INTEGER PRIMARY KEY,
  type         TEXT NOT NULL,         -- 'export' | 'runtime.build' | 'rollout.plugin' | 'rollout.runtime' | 'rollout.models' | 'instance.recreate'
  title        TEXT NOT NULL,
  status       TEXT NOT NULL CHECK (status IN ('queued','running','paused','succeeded','failed','partial','canceled')),
  params_json  TEXT NOT NULL,
  strategy_json TEXT,                 -- {concurrency, canary, maxFailureRatio, restart}
  total        INTEGER NOT NULL DEFAULT 0,
  done         INTEGER NOT NULL DEFAULT 0,
  failed       INTEGER NOT NULL DEFAULT 0,
  created_by   INTEGER REFERENCES users(id),
  created_at   TEXT NOT NULL,
  started_at   TEXT,
  finished_at  TEXT,
  error        TEXT
);
CREATE TABLE job_tasks (
  id          INTEGER PRIMARY KEY,
  job_id      INTEGER NOT NULL REFERENCES jobs(id) ON DELETE CASCADE,
  seq         INTEGER NOT NULL,       -- 执行顺序（金丝雀排前面）
  user_id     INTEGER REFERENCES users(id),
  status      TEXT NOT NULL CHECK (status IN ('pending','running','succeeded','failed','skipped','canceled')),
  attempt     INTEGER NOT NULL DEFAULT 0,
  payload_json TEXT,                  -- plan() 产出的每任务参数（重启后据此复原任务；WP4 定稿）
  log         TEXT NOT NULL DEFAULT '', -- 追加写，单条上限 256KB（超出截断头部）
  result_json TEXT,
  started_at  TEXT,
  finished_at TEXT,
  error       TEXT
);
CREATE INDEX job_tasks_job ON job_tasks(job_id, seq);

CREATE TABLE exports (
  id           INTEGER PRIMARY KEY,
  user_id      INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  job_id       INTEGER REFERENCES jobs(id),
  parts_json   TEXT NOT NULL,          -- ["workspace","sessions","settings"]
  format       TEXT NOT NULL CHECK (format IN ('zip','tar.gz')),
  status       TEXT NOT NULL CHECK (status IN ('queued','running','ready','failed','expired')),
  file_name    TEXT,                   -- 仅作下载名：dsh-<username>-20261012-2130.zip（ASCII）；落盘名为 exports/<slug>/<id>.<ext>
  size_bytes   INTEGER,
  sha256       TEXT,
  created_at   TEXT NOT NULL,
  expires_at   TEXT,
  downloaded   INTEGER NOT NULL DEFAULT 0,
  error        TEXT
);
```

### 1.4 插件 / 版本 / 模型域（WP3）

```sql
CREATE TABLE runtimes (
  id           INTEGER PRIMARY KEY,
  dsh_version  TEXT NOT NULL UNIQUE,   -- '0.2.0-rc.2'
  image        TEXT NOT NULL,          -- 'dshhub/runtime:0.2.0-rc.2'

  is_default   INTEGER NOT NULL DEFAULT 0,

  size_bytes   INTEGER,

  created_at   TEXT NOT NULL
);

CREATE TABLE plugins (
  id            INTEGER PRIMARY KEY,
  package_name  TEXT NOT NULL UNIQUE,  -- npm 包名，如 'dsh-email'、'@local/dsh-file-download'
  display_name  TEXT NOT NULL,
  description   TEXT NOT NULL DEFAULT '',
  icon          TEXT,                  -- 图标（ph 图标名或 data URL）

CREATE TABLE plugin_platforms (             -- 某插件在某平台上的设置；有行 = 出现在该平台的库里
  plugin_id     INTEGER NOT NULL REFERENCES plugins(id) ON DELETE CASCADE,
  platform      TEXT NOT NULL CHECK (platform IN ('cloud','desktop')),
  policy        TEXT NOT NULL DEFAULT 'optional'
                CHECK (policy IN ('required','default','optional','hidden')),
  bundle_order  INTEGER NOT NULL DEFAULT 100,
  config_yaml   TEXT NOT NULL DEFAULT '',
  needs_restart INTEGER NOT NULL DEFAULT 1,
  created_at    TEXT NOT NULL,
  updated_at    TEXT NOT NULL,
  PRIMARY KEY (plugin_id, platform)

-- plugins 的 policy/bundle_order/config_yaml/needs_restart 保留为**云上行的镜像**（旧代码读它不出错），
-- 写入一律经 plugin_platforms，由服务层同步镜像列。

CREATE TABLE plugin_versions (
  id           INTEGER PRIMARY KEY,
  plugin_id    INTEGER NOT NULL REFERENCES plugins(id) ON DELETE CASCADE,

  version      TEXT NOT NULL,          -- 同名版本号可以在两个平台各有一条
  source_type  TEXT NOT NULL CHECK (source_type IN ('npm','tarball','local','upload')),
  source_ref   TEXT NOT NULL,          -- npm: 'dsh-email@0.16.0'；tarball: URL；local: 宿主目录；upload: 原文件名
  spec         TEXT NOT NULL,          -- 写进 package.json 的依赖说明：'0.16.0' | URL | 'file:/opt/hub/plugin-store/<file>.tgz'
  store_file   TEXT,                   -- plugin-store/ 下的 tgz（local/upload 才有）
  sha256       TEXT,
  min_dsh      TEXT,                   -- 兼容的最低 DSH 版本（可空）
  created_at   TEXT NOT NULL,

CREATE TABLE user_plugins (               -- 「期望状态 + 实际状态」
  user_id        INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  plugin_id      INTEGER NOT NULL REFERENCES plugins(id) ON DELETE CASCADE,
  desired        TEXT NOT NULL CHECK (desired IN ('installed','absent')),
  desired_version_id INTEGER REFERENCES plugin_versions(id),
  actual_version_id  INTEGER REFERENCES plugin_versions(id), -- 为空 = 未安装
  state          TEXT NOT NULL CHECK (state IN ('synced','pending','failed')),
  source         TEXT NOT NULL DEFAULT 'admin' CHECK (source IN ('admin','user','policy')),
  error          TEXT,
  updated_at     TEXT NOT NULL,
  PRIMARY KEY (user_id, plugin_id)
);

CREATE TABLE model_providers (
  id             INTEGER PRIMARY KEY,
  route_key      TEXT NOT NULL UNIQUE, -- DSH 里的 provider 路由名：小写连字符，如 'hub-relay'
  display_name   TEXT NOT NULL,
  kind           TEXT NOT NULL CHECK (kind IN ('pi-ai','deepseek-official')),
  api            TEXT,                 -- pi-ai：'openai-completions' | 'openai-responses' | 'anthropic-messages'
  base_url       TEXT,
  models_json    TEXT NOT NULL DEFAULT '[]', -- [{id,name,contextWindow,maxTokens,input,reasoningEfforts}]；input ⊆ [text,image]
  compat_json    TEXT,
  extra_json     TEXT,                 -- 其余 pi-ai 字段原样透传（headers、retryPolicy…）
  key_mode       TEXT NOT NULL CHECK (key_mode IN ('shared','per-user','none')),
  api_key_enc    TEXT,                 -- key_mode=shared 时使用
  enabled        INTEGER NOT NULL DEFAULT 1,
  created_at     TEXT NOT NULL,
  updated_at     TEXT NOT NULL

CREATE TABLE user_provider_keys (
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  provider_id INTEGER NOT NULL REFERENCES model_providers(id) ON DELETE CASCADE,
  api_key_enc TEXT NOT NULL,
  updated_at  TEXT NOT NULL,
  PRIMARY KEY (user_id, provider_id)
);
CREATE TABLE model_presets (
  id                 INTEGER PRIMARY KEY,
  platform           TEXT NOT NULL DEFAULT 'cloud'
                     CHECK (platform IN ('cloud','desktop')),  -- 迁移 124：每个平台一套「模型配置」
  name               TEXT NOT NULL,     -- 只在平台内唯一（UNIQUE(platform, name)）
  description        TEXT NOT NULL DEFAULT '',
  provider_ids_json  TEXT NOT NULL,     -- [1,2]
  default_provider   TEXT NOT NULL,     -- route_key
  default_model      TEXT NOT NULL,
  is_default         INTEGER NOT NULL DEFAULT 0,
  revision           INTEGER NOT NULL DEFAULT 1, -- 每次修改 +1，写进 managed.patch.yml 头部注释
  created_at         TEXT NOT NULL,
  updated_at         TEXT NOT NULL,
  UNIQUE (platform, name)
);
-- 每个平台最多一个默认预设：CREATE UNIQUE INDEX model_presets_one_default ON model_presets(platform) WHERE is_default = 1;
-- 桌面平台的「下发到 DSH」勾选集合存在 settings.relay_dsh_desktop（云上仍用 relay_routes.dsh_enabled）。

CREATE TABLE model_catalog (

  model_id   TEXT NOT NULL,     -- 管理员填的原始写法（展示用）
  info_json  TEXT NOT NULL,     -- {name?, contextWindow?, maxTokens?, input?, reasoningEfforts?}
  updated_at TEXT NOT NULL
);
```

### 1.4e 桌面端（WP25a–WP25e，迁移 120 / 121 / 122）

混合实例的桌面半边（20 §5、桌面端设计裁决（未随开源版发布））。三条硬纪律：**列集合就是隐私白名单**
（没有 "raw payload" 列，除 `name` / `capabilities_json` 外每个 TEXT 列都有枚举 CHECK 或长度约束）、
**时间一律服务端时钟**、**明文秘密不落库**（令牌只存 sha256，中转站密钥另有 `key_enc` 供 Hub 复用）。

| 表 | 迁移 | 关键列与约束 |
| --- | --- | --- |
| `desktop_devices` | 120 | `device_id`（`dv_` + 32 hex，**服务端生成**，裁决 #1）、`user_id`（CASCADE）、`install_key`（= `sha256('<userId>:<installId>')`，按用户加盐，原始 installId 不落库）、`name`（≤64 字，唯一自由文本列）、`platform`(`win32|darwin|linux`)、`os_major`（≤8 字符，只存主版本）、`arch`、`app_version`、`app_channel`(`nightly|latest`)、`runtime_version`、`applied_revision` / `applied_at` / `apply_state`(`unknown|applied|partial|pending|failed`) / `apply_error`（枚举码，**不存原文**）/ `apply_error_count`(0–100)、`capabilities_json`（唯一 JSON 列，≤256 字节）、`registered_at` / `first_seen_at` / `last_report_at` / `last_auth_at`、`status`(`active|revoked`) + `revoked_at` / `revoked_by` / `revoke_reason`(`user|admin|user-deleted|user-disabled|password-change|expired`)、`relay_key_id`（逻辑外键 → `relay_keys`，吊销设备时一起吊销）。部分唯一索引 `(user_id, install_key) WHERE status='active'` = **同一台机器重登复用同一行**（WP25e 交付物 8 的库级保证） |
| `desktop_device_plugins` | 120（123 加 `bundled`） | 主键 `(device_id, package_name)`；`version`、`source`(`hub-core|hub-default|hub-optional|user|bundled`，`bundled` = 客户端自带插件，docs/22 §4.2)、`state`(`enabled|disabled|failed|absent`)、`error_code`（枚举码，仅 failed 时有值）、`updated_at`。每次上报**整表替换**，上限 200 行/设备；索引 `(package_name, version)` 回答「谁装了 X」 |
| `desktop_device_tokens` | 121 | 主键 = `sha256(令牌明文)` hex；`device_id` / `user_id`（CASCADE）；`expires_at`（滑动 30 天，绝对上限 `created_at + 90 天`）、`renewed_at`、`revoked_at` + `revoked_reason`(`logout|rotated|device-revoked|password-change|user-disabled|user-deleted|expired`)、`replaced_by`（轮换链，`ON DELETE SET NULL`）、`ip` / `user_agent` / `app_version`（签发时元信息，**不对外返回**）。**过期超过 30 天的行由定时任务清理**（WP25e 交付物 9：onReady + 每小时，删>0 行才写一条 `desktop.tokens.cleanup` 审计） |
| `desktop_delivery_counter` / `desktop_deliveries` | 122 | 发布计数器（单行 `id=1`）与**只追加**的发布日志（`revision` 主键、`scope`(`all|role|user`)、`role`、`user_id`、`kind`(`plugin|config|app|uninstall|mixed`)、`actor_id`、`detail_json`）。设备的 `desiredRevision` = 作用于它的行的 `max`（纯函数、可解释、可重放）；空清单保留 revision 1，首次发布从 2 起，后续 +1。计数器初值仍为 0，不修改迁移或历史发布行 |
| `desktop_plugin_targets` / `desktop_config_fragments` / `desktop_uninstall_targets` | 122 | 期望状态（按 全部 / 角色 / 用户 三档作用域，`CHECK` 锁死 role 与 user_id 的组合）；配置片段的 `config_json` 只存**已过白名单校验**的内容 |
| `desktop_channel_policies` / `desktop_policy_overrides` / `desktop_update_floor` | 122 | 版本策略、按角色/用户的覆盖、全局强更地板（地板登录前就生效，只能走 `PUT /api/admin/desktop/update-floor` 改，单独审计 `desktop.update-floor.set`） |
| `desktop_plugin_artifacts` | 122 | 插件桌面整包（裁决 #16：claude 二进制包一律拒收；每插件只留最近 2 版） |
| `desktop_releases` | 122 | 安装包 + blockmap（sha512、字节数、`target`、`channel`、`version`、`yanked_at`）；feed YAML 由此生成 |

`presence`（在线/离线）**不落库**：`status='revoked'` → `revoked`；`last_report_at >= now - settings.desktop.offlineAfterSec`
→ `online`；否则 `offline`（04 §11.4 与概览 `desktop` 计数同一判定）。审计里设备相关的动作统一
`target_type='desktop.device'` + `target_id=<deviceId>`，所以设备详情只按这两列取最近 20 条（且**不返回 `actor_ip`**）。

### 1.5 Quota（`users.quota_json` 与 `settings.default_quota`）

```ts
type Quota = {
  cpus: number          // 0.5–8，默认 2
  memoryMb: number      // 512–8192，默认 4096（2026-10-15 由 2048 调高）
  pidsLimit: number     // 默认 1024
  diskGb: number        // 工作区+home 软上限，默认 20
  idleStopMinutes: number // 0 = 不自动停，默认 120
  idleNoClientMinutes: number // 没人看（无打开的 WS）时多久休眠，默认 30；0 = 沿用 idleStopMinutes（WP33）
  allowUserPlugins: boolean // 是否允许用户自助安装 optional 插件，默认 true
}
```

## 2. 磁盘布局（`HUB_DATA_DIR`）

```
HUB_DATA_DIR/                       生产：/srv/dsh-hub（属主 = 跑 Hub 的系统用户，0750）
├── hub.db, hub.db-wal, hub.db-shm
├── secrets/                        0700
│   ├── master.key                  0600，32 字节随机
│   └── tls/ ca.crt ca.key server.crt server.key
├── avatars/                        <userId>-<sha256前12>.webp|png|jpg
├── users/<slug>/                   0700
│   ├── home/                       → 容器 /home/dsh（HOME）
│   │   └── .dsh/                   → DSH_HOME
│   │       ├── .credentials.yaml   DSH 写，含 browser-session 密钥（Hub 只读）
│   │       ├── profiles/web/       package.json、cordis.patch.yml、cordis.yml、node_modules/
│   │       ├── sessions/ attachments/ storages/ logs/ ...
│   ├── workspace/                  → 容器 /workspace（默认工作区）
│   └── managed/                    → 容器 /opt/hub/managed（只读）
│       ├── managed.patch.yml       Hub 渲染：模型提供方 + 默认模型 + 插件配置
│       └── manifest.json           渲染来源与版本（presetRevision、插件版本列表、生成时间）
├── plugin-store/                   → 容器 /opt/hub/plugin-store（只读）
│   └── <safe-package-name>-<version>.tgz
├── runtime-build/<version>/        镜像构建上下文与日志
├── exports/<slug>/<exportId>.zip
├── trash/<slug>-<时间>/            删除用户后的数据保留 7 天（`users.trash_dir` 指向它；恢复时搬回 users/<slug>，彻底删除/过期时 rm）
└── logs/                           hub-api 滚动日志（systemd 下也进 journal）
```

**归属规则**：`users/<slug>/home` 与 `workspace` 由容器写（uid 1000）；`managed/` 只由 Hub 写；
Hub 修改 `home/.dsh/profiles/web/package.json` 时必须先确认容器内没有并发的 pnpm 进程（通过任务锁，见 06 §3）。

**用户回收站（04 §4.2）**：删除用户 = 软删除 + `username` 改墓碑名 `<原名>#del<id>`（释放用户名，同名可立即新建）
+ 数据目录移入 `trash/`（`purge=true` 时不保留）。7 天内管理端可恢复（`restore`）/彻底删除（`purge`）；
超期条目由后台清理任务自动彻底删除。墓碑名不满足 `USERNAME_REGEX`，永远无法被注册或登录。
